LeetCode Solutions

My solutions to LeetCode problems, written primarily in Python, as I practice data structures and algorithms.

About
This repo is a personal log of problems I've solved — including my thought process, edge cases I ran into, and optimizations along the way (e.g. brute force → optimal).

Approach
For each problem, I try to:
Start with a working brute-force solution
Analyze its time/space complexity
Optimize where possible (e.g. hashing, two pointers, sliding window)
Note the final complexity in code comments
